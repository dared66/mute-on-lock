# Security policy

## Supported version

Security fixes are applied to the latest commit on the default branch.

## Reporting a vulnerability

While this repository is private, contributors with access can open an issue;
it is visible only to repository collaborators. Before changing the repository
visibility to public, the owner should enable **Private vulnerability reporting**
under **Settings → Security → Code security and analysis**. After publication,
report vulnerabilities through the **Security** tab rather than a public issue.

Mute on Lock runs without administrator privileges and has no network access or
third-party runtime dependencies. Its installed executable, configuration, login
item, and logs live in the current user’s home directory.
