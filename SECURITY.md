# Security policy

## Supported version

Security fixes are applied to the latest commit on the default branch.

## Reporting a vulnerability

Please use **Report a vulnerability** in the repository’s **Security** tab. This
opens a private discussion with the maintainer. Do not disclose an unpatched
vulnerability in a public issue.

Mute on Lock runs without administrator privileges and has no network access or
third-party runtime dependencies. Its installed executable, configuration, login
item, and logs live in the current user’s home directory.
